The flow runs for gf180_9t and sky130_12t cell libraries denoted by t9 and t12 directories respectfully. 

Run the flow with: 
```
make
```

To clean the top directory, run this command:
```
make clean
```

To clean and purge the synth and pnr subdirectories, run this command:
```
make purge
```

This flow also outputs a latex table with the metrics found once the synth and pnr flows are complete."
